# معرّفات التوافق التاريخية — Elvorance Enterprise

اسم المنتج الحالي هو **Elvorance Enterprise**، ومساحات العمل البرمجية تستخدم `@elvorance/*`.

بعض المعرّفات التقنية القديمة متصلة بقواعد البيانات أو وسيط الرسائل أو بيانات المتصفحات السابقة، ولذلك لا يمكن تغييرها باستبدال نصي دون ترحيل فعلي:

- أسماء قواعد PostgreSQL وأدوارها `atlas_*`.
- قيم `COMPOSE_PROJECT_NAME` القديمة وأسماء صور Docker التي قد تعتمد عليها بيئات قائمة.
- مستخدم RabbitMQ واسم الـvhost والـexchange والـqueues الحالية.
- مفاتيح التخزين السابقة في المتصفح، التي قد تتضمن بيانات تجربة ينبغي تقييمها قبل إزالتها.
- مسار `/opt/atlas/check-isolation.sh` داخل الحاوية، طالما بقي mount في Compose يستخدمه.

لا تمثل هذه المعرّفات اسمًا تجاريًا للمنتج. يجب تغييرها لاحقًا عبر migration ذات نسخ احتياطي، واختبارات استعادة، وخطة cutover/rollback، وتحديث للـcredentials والعملاء، وليس بعملية إعادة تسمية جماعية.

**حد التكامل الحالي:** الواجهات الثلاث لا تزال تستخدم مخزن demo محليًا. نجاح CI يفحص البناء والاختبارات الآلية، ولا يثبت تكامل كل شاشة مع الخدمات أو PostgreSQL. راجع `MIGRATION-MATRIX.md` قبل إعلان جاهزية الإنتاج.
