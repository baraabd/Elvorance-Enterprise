# ADR-001 — ثلاثة عملاء وملكية واضحة للمكونات

الحالة: معتمد في بنية 2.0.

## القرار

تظل التطبيقات الثلاثة workspaces منفصلة، مع `design-system` و `ui` و `app-runtime` مشتركة. يحصل الهاتفان على مشروعي Capacitor مستقلين. لا تُعاد كتابة الشاشات لمجرد تغيير شكل المستودع، ولا ينتقل تنفيذ شاشة إلى تطبيق آخر.

المرجع هو 64 مسارًا في 1.1، ومطابقة مصدر الأصول والتسجيلات والسلوك تحت بيانات ثابتة. يحتاج الادعاء بالمطابقة البصرية إلى لقطات قبل/بعد في محرك وأبعاد ثابتة؛ فحص DOM وحده لا يثبت هندسة العرض. ملفات native لا تثبت بناء Android أو iOS.

## النتائج

يمكن بناء كل عميل ونشره بصورة مستقلة، وتصل إصلاحات الخطوط والأزرار من الحزمة المالكة. تبقى بيانات العرض التجريبية منفصلة عن عميل HTTP. لا يجوز إخفاء نقص الربط بالخادم وراء واجهة تبدو مكتملة. يسجل `MIGRATION-MATRIX.md` كل فجوة قبول ظاهرة.
